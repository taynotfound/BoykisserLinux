Boykisser Linux 2 is a rewrite of most of the system. Here's what changed since the last release:

- New :3 logo on the boot menu, splash screen, installer, login screen and desktop
- Six new wallpapers, drawn from code in the repo instead of found online
- KDE Plasma as an install option, themed the same way as XFCE
- Optional app bundles in the installer: gaming, streaming, development and office
- contrib and non-free are enabled, so Steam and the NVIDIA driver install without extra setup
- The Boykisser tools now ship as Debian packages and `boykisser update` keeps them current
- Fixed: picking KDE or app bundles in the installer did nothing, and the live account ended up on installs
- Fixed: the boot menu art covered the BIOS menu, and Qt apps ignored the theme
- The live session login is now `live` / `live`, so `user` is free as a username
- New website and docs at boykisser.taymaerz.de
- New version numbers: vMAJOR.MONTH.YY.N, starting at v2.10.26.4
